MiBeeNvr

GoReact⭐ 旗舰

轻量级自托管 NVR（网络视频录像机）。单个静态二进制、零依赖、内嵌 Web UI，低功耗 ARM 设备即可运行。

  • RTSP / ONVIF / GB28181 / 小米 / WHIP 摄像头接入，RTMP / SRT 推流
  • WebRTC / HLS / FLV 直播与连续回放，音频与延时摄影
  • S3 冷存储卸载、浏览器端 AI 检测

MiBeeSteward

GoSvelteKit

设备管理与监控系统（CMDB-lite）。Go 后端（Chi + SQLite，CGO-free）内嵌 SvelteKit 5 SPA，单二进制部署。

  • SNMP / ICMP / TCP / HTTP 探测，插件化 v2 网络扫描
  • 分布式 Agent 架构：agent 扫描内网，中心统一登记
  • 心跳监测、资产台账、Prometheus 指标

MiBeeBell 🔒 源码私有

Go告警中心

轻量自托管告警通知中心。事件摄取、去抖、冷却、升级、静默与多渠道投递共用一条管道，支持 mesh 高可用。

  • 七类事件入口，兼容 Alertmanager / Bark / MQTT
  • 国内外通知渠道、按人订阅与多站点联邦
  • CGO-free 单二进制，内嵌双语 Web UI 与 SQLite

MiBeeReach 🔒 源码私有

Rust远程接入

自部署、隐私可控的统一远程接入平台。远程桌面、终端、SSH 与内网隧道共享连接层和设备身份。

  • 会话级控制、剪贴板与文件权限

MiBeeVision Lite 🔒 源码私有

Rust视频 AI

MiBeeNvr 的服务端视频 AI 引擎。对录像逐段进行目标检测、多目标跟踪与区域规则判定，并把事件和快照回写 NVR。

  • 内置 YOLOv8n + ONNX Runtime CPU 推理
  • ByteTrack 跟踪，区域入侵 / 越界 / 徘徊规则
  • 图形化配置页，事件与带框快照回写 NVR

About the Hive

关于蜂巢

「技术赋能生活，专业成就无忧」
Technology empowers life; professionalism brings peace of mind.

Mi 取自创始人网名 Mickeyzzc，Bee 来自他的爱人 —— 两只蜜蜂把家安在了代码里。 我们以全栈工程能力解决实际问题：软件开发、AI 应用、物联网、云原生、可观测性与系统集成。

除了公开仓库，蜂巢里还有一批私有维护的产品：运维工具链供应链中枢 MiBeeHive、 统一远程管理平台 MiBeeReach、视频 AI 引擎 MiBeeVision、边缘运维 Agent Kite 与统一设备交互协议 MDP。 其中告警通知中心 MiBeeBell、MiBeeReach 与 MiBeeVision 的功能介绍与二进制已在 mickeyzzc/releases 发布；MiBeeHive 暂无可下载版本。
