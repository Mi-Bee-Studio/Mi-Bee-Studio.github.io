MiBeeNvr

GoReact⭐ 旗舰

轻量级自托管 NVR（网络视频录像机）。单个静态二进制、零依赖、内嵌 Web UI，低功耗 ARM 设备即可运行。

  • RTSP / ONVIF / GB28181 / 小米 / WHIP 摄像头接入，RTMP / SRT 推流
  • WebRTC / HLS / FLV 直播与连续回放，音频与延时摄影
  • S3 冷存储卸载、浏览器端 AI 检测
github.com/Mi-Bee-Studio/MiBeeNvr ↗

MiBeeSteward

GoSvelteKit

设备管理与监控系统（CMDB-lite）。Go 后端（Chi + SQLite，CGO-free）内嵌 SvelteKit 5 SPA，单二进制部署。

  • SNMP / ICMP / TCP / HTTP 探测，插件化 v2 网络扫描
  • 分布式 Agent 架构：agent 扫描内网，中心统一登记
  • 心跳监测、资产台账、Prometheus 指标
github.com/Mi-Bee-Studio/MiBeeSteward ↗

mibee-docs

MarkdownMermaid

全组织文档中心：所有项目双语（中 / 英）手册的单一事实源，branch-per-team 治理，squash-only 合并。

仓库 ↗ 在线阅读 www.mickeybee.cn/docs ↗

mibee-fingerprints-go

GoYAML

MiBee 指纹库参考引擎：加载内嵌 YAML 规则（零配置），把采集到的证据分类为 ServiceIdentity，实现 MiBeeSteward 指纹规范。

github.com/Mi-Bee-Studio/mibee-fingerprints-go ↗

MiBee Cam Family

相机固件

把每一块 ESP32 变成正经的 IP 摄像机：MJPEG / RTSP 流、ONVIF、移动侦测、Web OTA，Prometheus 指标。
